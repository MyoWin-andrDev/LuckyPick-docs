    Graphic Design Workload

    Designer: Min

    Pure graphic design assets required for LuckyPick EuroMillions — distinct from UI/UX screen layouts. These are bespoke illustrations, brand assets, and marketing visuals that Min produces.

    Summary

    Asset Category Deliverables
    Number Ball Illustrations 50 assets
    Lucky Star Illustrations 12 assets
    App Icon 1 master + exports
    Lucky Mode Icons 9 icons
    Sharing Card Templates 10 templates (9 modes + Quick Pick)
    App Store / Play Store Marketing ~12 assets
    Total distinct deliverables ~85

    1. Number Ball Illustrations

    50 individual illustrated balls, one per number (1–50).

    Each ball must:

    • Render as a 3D-style sphere — glossy, metallic, or with a soft depth effect — matching the premium aesthetic of EuroMillions's visual language
    • Display its number clearly in the centre, readable at small sizes (e.g. 40×40 px in a row of results)
    • Feel cohesive as a set — same lighting angle, same material treatment, same number typography
    • Export clean on dark backgrounds (transparent PNG or SVG)

    Colour is not customisable

    Lucky Color Mode changes the algorithm, not the ball colours. All 50 main number balls always use the same consistent colour set regardless of user inputs.

    Colour grouping reference (EuroMillions visual language):

    Numbers Ball Colour
    1–9 White / silver
    10–19 Deep blue
    20–29 Deep red
    30–39 Violet / purple
    40–50 Gold / amber

    The exact colour split above is a suggestion — the graphic designer should validate against official EuroMillions ball imagery and match the premium dark-theme palette of the app.

    2. Lucky Star Illustrations

    12 individual illustrated Lucky Stars, one per number (1–12).

    Each Lucky Star must:

    • Be visually distinct from the main number balls — typically gold/amber star shape, or a rounded star-themed badge
    • Display its number clearly
    • Share the same material/lighting language as the number balls
    • Export at the same sizes as the balls

    3. App Icon

    1 master icon design.

    • Size: 1024×1024 px master (Xcode and Android Studio auto-export smaller sizes)
    • Subject: a single memorable image — e.g. a stylised star, a glowing ball, a gold lucky star on dark navy
    • Must remain legible at 60×60 px (iPhone home screen) and 20×20 px (notification icon)
    • Must work on iOS (square with automatic rounding) and Android (adaptive icon with foreground + background layers)
    • Dark navy background (#080E18) as the base
    • No fine detail that disappears at small sizes

    Export requirements:

    Platform Format Sizes
    iOS PNG (no alpha) 1024, 180, 120, 87, 80, 76, 60, 58, 40, 29, 20 px
    Android PNG (foreground + background) 512, 192, 144, 96, 72, 48 px
    Web (docs / website) PNG or SVG 512, 192 px

    4. Lucky Mode Icons

    9 icons, one per Premium Lucky Mode.

    Used on the Lucky Modes browser screen and on the result card as a mode badge.

    Mode Icon Concept
    Birthday Mode Cake / birthday star
    Horoscope Mode Zodiac wheel / constellation
    Pet Mode Paw print
    Family Mode Group of people / family circle
    Lucky Color Mode Colour palette / swatches
    Lucky Number Mode A stylised numeral (e.g. "7") with a glow
    Hot & Cold Mode Flame paired with a frost crystal
    Odd-Even Mode Split circle / odd-even dial
    Smart Mix AI spark / mixed sphere cluster

    Style: outlined or filled, matching the app's gold/navy design language. Consistent stroke weight and scale across all 9.

    5. Social Sharing Card Templates

    10 illustrated card templates, one per Lucky Mode.

    When a user shares their LuckyPick, the app generates a static image card automatically. The card displays:

    • App name / logo
    • The 5 main number balls + 2 Lucky Star balls (using the ball illustrations from §1–2 above)
    • The Lucky Mode name and mode icon
    • The personal label where applicable (e.g. "Leo", "Charlie", "Family Mode")
    • Website URL: luckypick.eu

    Per-mode accent differentiation:

    Each card uses the same structural layout but has a different visual accent tied to its mode:

    Mode Card Accent
    Quick Pick Neutral gold gradient
    Birthday Mode Confetti / bokeh pastel overlay
    Horoscope Mode Constellation / starfield background
    Pet Mode Paw print texture / playful palette
    Family Mode Warm subtle glow, family-themed accent
    Lucky Color Mode Subtle wash of the user's selected colour
    Lucky Number Mode Bold number typography in background
    Hot & Cold Warm ember fading into cool frost
    Odd-Even Split field, warm against cool
    Smart Mix Geometric mixed-sphere cluster

    Format: each template is provided as a PSD / Figma source + a flat PNG reference. The developer generates the final images programmatically (Flutter's canvas_kit or screenshot package), but they need a reference for the background layer and accent treatment.

    Dimensions: 1200×630 px (standard Open Graph share card). Must look good when cropped to square (1080×1080) by Instagram/social media.

    6. App Store & Google Play Marketing Assets

    These are required before the app can be submitted to either store.

    App Store (iOS)

    Asset Size Count
    iPhone 6.9" screenshots 1320×2868 px 3–10
    iPhone 6.5" screenshots 1242×2688 px 3–10 (can reuse 6.9")
    iPad 12.9" screenshots 2048×2732 px 3–10 (if iPad supported)
    App Preview video 1080×1920 px, ≤30s, MP4 0–3 (optional)

    Google Play (Android)

    Asset Size Count
    Phone screenshots 1080×1920 px (min) 2–8
    Feature graphic (banner) 1024×500 px 1 (required)
    Tablet 7" screenshots 1200×1920 px 2–8 (optional)
    Promo video YouTube URL optional

    Screenshot Content (required scenes)

    Each screenshot is a composed marketing image — not a raw simulator screenshot. It includes a device frame, a headline, and the screen content.

    # Scene Highlights
    1 Home Screen "Generate your EuroMillions lucky numbers"
    2 Lucky Mode Selection "9 unique Lucky Modes"
    3 Horoscope / Birthday Mode result "Numbers that match you"
    4 My Picks set "Save and manage up to 12 combinations"
    5 Results & Draw History "Live EuroMillions results & full prize breakdown"
    6 Statistics Screen "Data-driven insights — Hot, Cold & Trending"
    7 Premium Screen "Unlock all Lucky Modes — 100% ad-free"

    Graphic designer produces the composed layouts; the developer provides the screen content via simulator screenshots.

    7. What Is NOT Graphic Design Work

    The following are UI/UX design tasks (separate scope):

    • Screen wireframes and high-fidelity screen mockups in Figma/Sketch
    • Navigation flows and interaction states
    • Typography hierarchy, spacing, and grid system
    • Dark / light theme colour tokens
    • Icon selection from an icon library (SF Symbols / Material Icons)
    • Component specs for developers

    Those tasks are covered in the UI/UX Workload page.

    Recommended File Deliverables

    File Format Notes
    Number balls (50) SVG + PNG 3× Transparent background
    Lucky Stars (12) SVG + PNG 3× Transparent background
    App icon PNG 1024 + Adaptive layers No alpha for iOS base
    Mode icons (9) SVG + PNG 2× Transparent background
    Sharing card templates (10) Figma / PSD + PNG flat 1200×630 + 1080×1080 crop
    App Store screenshots (iOS) PNG Per Apple spec sizes
    Play Store screenshots (Android) PNG + 1024×500 feature graphic Per Google spec
