    UI/UX Workload

    Complete breakdown of all UI/UX design tasks required for LuckyPick EuroMillions, based on the 11-document specification.

    Scope Summary

    Category Screens / Deliverables
    Onboarding & Launch 2
    Home & Generation 3
    Lucky Modes 12
    My Picks & Saved Sets 3
    Results & Draw History 3
    Statistics 1
    Notifications 1
    Premium & IAP 2
    Social Sharing 1
    Settings / More 1
    Empty & Error States ~10
    Total ~39 screens

    1. Onboarding & Launch

    Splash Screen

    • Short branded splash (~1 second)
    • LuckyPick logo centred on dark navy background
    • No interaction — auto-advances to Welcome

    Welcome Screen

    • Single screen — no multi-step onboarding
    • Clear GET STARTED primary button
    • Language auto-detection indicator
    • Legal disclaimer at the bottom (small, readable):
      "LuckyPick is an independent application and is not affiliated with EuroMillions or any official lottery operator."
    • Discreet notification permission pre-prompt (optional, before OS dialog)

    2. Home Screen

    Main Home

    • GENERATE MY NUMBERS primary action button (prominent, aurora/gold)
    • Free pick counter visible: "3 free picks remaining today"
    • Horizontal scroll preview of Lucky Modes (Birthday · Horoscope · Pet · Family)
    • View All Lucky Modes → link
    • Discover Premium section (tasteful, never aggressive)
    • No separate jackpot amount display — results are in the Results tab

    Generated Numbers Screen

    • 1–1.5 second reveal animation
    • 5 main number balls + 2 Lucky Stars displayed
    • Lucky Mode badge (e.g. "Horoscope Mode — Leo")
    • Three actions below: Save · Generate Again · Share

    Free Limit Reached State

    • Friendly message: "You've used your 3 free Lucky Picks for today. Come back tomorrow or unlock Premium."
    • UNLOCK PREMIUM CTA
    • No negative / punishing tone

    3. Lucky Modes Screens

    Lucky Modes Browser

    • Grid or list of all 10 Premium Modes + Quick Pick
    • Each mode has its own icon and a short one-line description (revealed on tap, not always visible)
    • Premium modes show a gold PREMIUM label — no large padlock icons
    • Free users can tap any premium mode and read the description before seeing the upgrade prompt

    Mode Input Screens (one per mode)

    Mode Input Fields UX Notes
    Birthday Mode Name/Nickname (optional), Date of Birth (DD/MM/YYYY) Date picker; must transform internally — not raw day/month
    Horoscope Mode Day + Month only (no year) Auto-displays detected zodiac sign
    Pet Mode Pet Name, Animal Type (7 options) Animal type as tappable pill buttons; CHANGE PET option
    Family Mode Relationship selector + Name + DOB per member +ADD FAMILY MEMBER button; relationship dropdown with "Other → specify" field; EDIT FAMILY / START NEW FAMILY
    Lucky Color Mode 10 circular colour buttons (identical size/shape) SURPRISE ME button; selected circle gets subtle gold outline; colour must NOT change generated ball colours
    Lucky Number Mode 1–3 numbers (1–50) Number input with validation; selected numbers shown as chips; CHANGE LUCKY NUMBERS
    Hot / Cold / Trending / Smart Mix No personal input Stat-mode description only; GENERATE button

    Mode Result Screen (shared layout)

    • Shows the 5+2 combination result
    • Lucky Mode + personal label (e.g. "Pet Mode – Charlie")
    • ADD TO MY PICKS · GENERATE ANOTHER · CHOOSE ANOTHER MODE · CHANGE DETAILS · SHARE
    • Counter shows current My Picks total

    4. My Picks & Saved Sets

    My Picks Screen (Active Set)

    • Header: MY PICKS + combination count (e.g. "6 combinations")
    • Each combination shows: mode label · 5 main numbers · 2 Lucky Stars
    • Per-item ••• menu: Replace Combination · Remove Combination · Share LuckyPick
    • START NEW SET button (available as soon as 1 combination exists)
    • At 12 combinations: SET COMPLETE state with START NEW SET CTA

    Empty My Picks State

    • "No combinations yet"
    • CREATE YOUR FIRST LUCKY PICK button

    Saved Sets Screen

    • List of archived sets by date (e.g. "8 August 2026 – 6 combinations")
    • Tap to expand and view combinations with mode labels

    5. Results & Draw History

    Results Screen

    • Latest draw shown immediately on open — no tap required
    • Draw Date + 5 main number balls + 2 Lucky Stars (official ball/star visual style)
    • PRIZE BREAKDOWN section below: Tier · Prize Amount · Number of Winners (all available tiers)
    • "Prize information pending" state when numbers are published but prize data not yet available
    • Link to Draw History

    Draw History Screen

    • List of last 100 draws, newest first
    • Each row: Date + 5 numbers + 2 Stars
    • Tap any row to open Draw Detail

    Draw Detail Screen

    • Same layout as Results Screen
    • Full prize breakdown for that specific draw
    • ← Back to Draw History

    6. Statistics Screen

    • HOT NUMBERS — top 10 most frequent main numbers (last 100 draws)
    • COLD NUMBERS — bottom 10 least frequent
    • TRENDING — numbers with strongest recent uplift (last 20 vs 100 draws)
    • NUMBER FREQUENCY — frequency chart/bar for all 50 main numbers
    • LUCKY STAR FREQUENCY — frequency for all 12 Lucky Stars
    • Free users: limited preview of top 5 numbers only
    • Premium users: full statistics
    • Disclaimer always visible: "Historical frequency does not predict future results"

    7. Notifications Settings

    • Three independent toggles (ON/OFF):
    • Draw Reminders
    • Results Available
    • Jackpot Won
    • Available to Free and Premium users
    • No separate toggle for €100M+ High Jackpot (it is a variant of Draw Reminder)

    8. Premium Screens

    Premium Screen (Central — all entry points lead here)

    • Headline: "Make LuckyPick truly yours."
    • Benefits list: All 10 Lucky Modes · Unlimited Generations · Advanced Statistics · Unlimited My Picks · Future Premium Features
    • Three plan options:
    • MONTHLY — €8.99/mo, auto-renews
    • YEARLY — BEST VALUE — €79.99/yr, visually highlighted in gold, "SAVE ~26%"
    • LIFETIME — €179.99 once, no subscription
    • Clearly visible ✕ / Back button — no dark patterns
    • RESTORE PURCHASES link at bottom

    Do NOT include

    • "No Ads" as a Premium benefit (LuckyPick is ad-free for everyone)
    • Fake countdown timers or urgency messages
    • Hidden close buttons

    Post-Purchase Confirmation Screen

    • "Welcome to LuckyPick Premium. Premium is now active."
    • CONTINUE button — returns user directly to the feature they came from

    9. Social Sharing Flow

    • After tapping SHARE, the device native share sheet opens automatically
    • No template selection required — LuckyPick generates the card automatically
    • After sharing: stay on current result, preserve combination and My Picks

    10. Settings / More Screen

    Item Action
    Premium / Manage Premium Opens Premium Screen or subscription management
    Draw History Navigate to Draw History
    Notifications Navigate to Notification Settings
    Language Language selector
    Contact Support Opens support channel
    Rate LuckyPick Opens App Store / Play Store review
    LuckyPick Website Opens luckypick.eu in browser
    Restore Purchases Triggers StoreKit / Play Billing restore
    About LuckyPick Version, tagline, legal links
    Privacy Policy Opens policy URL
    Terms & Conditions Opens T&C URL

    About Screen

    • App name, version ("Version 1.0"), "100% Ad-Free" badge
    • Short description of LuckyPick
    • Privacy Policy + Terms & Conditions links
    • Tagline: "Made for lucky moments."

    11. Empty & Error States (UX Required)

    State Where
    Empty My Picks My Picks screen — no combinations yet
    Set Complete (12/12) My Picks — prompt START NEW SET
    No Saved Sets Saved Sets screen
    Results Pending Results screen — draw not yet available
    Prize Information Pending Results — numbers available, prize data not yet
    Free Limit Reached Home / Generator — 0 picks remaining
    Premium Mode Locked Lucky Mode tap — free user
    Purchase Failed / Cancelled After failed IAP — neutral message
    No Network When API calls fail — non-intrusive error
    Notification Permission Declined Gracefully proceed, no repeated prompts
