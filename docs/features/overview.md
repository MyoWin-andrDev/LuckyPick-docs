##  User Experience Principles

1. **Simplicity First:** Users should be able to generate a ticket combination within **2 seconds** of opening the app.
2. **Visual Elegance:** Clean typography, smooth gold button transitions, dark blue contrast.
3. **No Clutter:** No intrusive advertising, external promo popups, or unnecessary complexity.
