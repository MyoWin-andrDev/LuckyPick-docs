#  Premium Subscriptions & Purchases

LuckyPick EuroMillions operates a transparent **Freemium model** powered by native App Store and Google Play subscriptions.

---

##  Free vs Premium Access

```

                       LuckyPick Access                      
   
         FREE TIER                  PREMIUM TIER         
  • Quick Pick Generator      • All 5 Lucky Modes        
  • Tuesday/Friday Results    • Unlimited Saved Picks    
  • Basic Statistics          • Advanced Frequency Stats 
  • 100% Ad-Free              • €100M+ Jackpot Alerts    
   

```

---

##  Subscription Tiers & Billing

* **Weekly Subscription:** Short-term access for casual players.
* **Monthly Subscription:** Popular standard plan.
* **Annual Pass:** Best value discounted annual plan.

### Integration Requirements:
* **iOS:** StoreKit 2 native API integration.
* **Android:** Google Play Billing Library v6+.
* **Restore Purchases:** One-tap restore button present in Settings.
