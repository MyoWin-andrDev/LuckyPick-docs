    My Picks & Combination Management

    The My Picks screen allows users to manage, save, organize, and check their generated ticket combinations.

    Features & Constraints

    • Maximum Saved Combinations: Up to 12 combinations per saved set (representing standard lottery playslips).
    • Mode Mixing: Users can mix lines generated from different Lucky Modes (e.g. 2 Birthday lines + 2 Horoscope lines + 2 Hot/Cold lines) in a single set.
    • Duplicate Detection: Automatic filter prevents adding identical 5+2 number lines to the same set.

    Automatic Ticket Validation Checker

    When official EuroMillions draw results are published every Tuesday and Friday night, the Ticket Checker automatically validates all saved picks:

    Saved Ticket: [ 05 - 12 - 23 - 34 - 48 ] + [ 03 - 09 ]
Draw Result:  [ 05 - 12 - 23 - 41 - 50 ] + [ 03 - 11 ]
              -----------------------------------------
Match Output: 3 Main Numbers + 1 Lucky Star (Prize Tier 9 Winner! )

    Visual Highlights:

    • Matching numbers light up in Glowing Gold.
    • Displays winning prize tier and estimated prize payout.
