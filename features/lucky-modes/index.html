    Lucky Modes & Number Generation

    Every EuroMillions line is 5 main numbers (1–50) plus 2 Lucky Stars (1–12). LuckyPick's Lucky Modes are different ways of arriving at that line.

    Combination rules

    Rule Value
    Main numbers 5, drawn from 1–50, all distinct
    Lucky Stars 2, drawn from 1–12, all distinct
    Display order Always sorted ascending

    Every generator, every model validator and every API response honours this. The generation engine is pure Dart with no I/O, and a test suite asserts these invariants plus determinism across all 10 modes.

    Free generation

    Mode Notes
    Completely Random Uniform across the full range
    Quick Pick The default one-tap generation

    Free users get 3 generations per local calendar day, with no waiting period between them. See Premium.

    The 9 premium Lucky Modes

    Listed in Home-screen grid order — the app renders them as a 3×3.

    # Mode id Input Uses statistics
    1 Birthday Mode birthday Name (optional) + date of birth —
    2 Family Mode family Members: relationship + name + DOB —
    3 Pet Mode pet Pet name + animal type —
    4 Horoscope Mode horoscope Day + month → zodiac sign (no year) —
    5 Hot & Cold Mode hotCold none ✅
    6 Smart Mix Mode smartMix none ✅
    7 Lucky Color Mode luckyColor One of 10 colours, or SURPRISE ME —
    8 Lucky Number Mode luckyNumber 1–3 anchor numbers (1–50) —
    9 Odd-Even Mode oddEven none —

    All 9 unlock together — there is no partial unlock.

    Deviation from the source PDFs — approved 2026-08-22

    The original specification listed ten premium modes, with Hot Numbers and Cold Numbers separate and a Trending Mode. The approved design merges Hot and Cold into one card and adds Odd-Even Mode, giving nine for the 3×3 grid.

    Trending was removed as a generator only. It is still computed (latest 20 draws versus latest 100) and still shown on the Statistics screen.

    Behaviour

    • Premium modes stay visible to free users with a gold PREMIUM label — never hidden.
    • A free user can open a premium mode and read its description before being offered the upgrade.
    • Each mode has its own icon, accent colour and a short description.
    • Generation is deterministic: the same input in the same draw cycle produces the same line, so "Generate again" walks a variant space rather than rerolling blindly.
    • Generation avoids producing an exact duplicate of a line already in My Picks.

    Lucky Color Mode changes the algorithm, never the balls

    The chosen colour seeds the selection. It does not recolour the generated number balls — ball colours are fixed by the design system regardless of any user input.

    How the statistical modes work

    The rolling 100-draw window is the only dataset. See Results & History.

    Mode Strategy
    Hot & Cold The spec's balanced mix: 3 of the most frequently drawn numbers plus 2 of the most overdue. Stars take one from each pool.
    Smart Mix One hot, one cold, one trending, then fills from a flat pool. One statistical star plus one free star.
    Odd-Even Alternates a 3:2 and a 2:3 odd/even split per generation rather than fixing one — real draws are rarely all-odd or all-even. Needs no statistics.

    Where statistics are unavailable (offline, or a fresh install), the statistical modes fall back to a built-in distribution so they always return a valid line.

    Personal modes

    Mode Seeding
    Birthday Day, month and year digits are modulo-mapped into 1–50 and 1–12, then folded into the seed. Never a raw day/month copy.
    Horoscope Day + month resolve to one of the 12 zodiac signs; the sign's ruling numbers weight the selection.
    Pet Pet name letter values combined with an animal-type factor.
    Family Each member's relationship, name and date of birth contribute; the members are aggregated into one seed.
    Lucky Color The colour's prime drives an arithmetic progression across the range.
    Lucky Number The user's 1–3 anchors are kept; the rest of the line is filled around them.

    Statistics do not predict anything

    Historical frequency does not predict future results. Every draw is independent. The Statistics screen carries this disclaimer permanently, and no Lucky Mode may be described as improving the odds of winning.
