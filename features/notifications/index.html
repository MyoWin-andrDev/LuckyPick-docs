    Notifications & Reminders

    LuckyPick uses notifications to keep users informed about relevant EuroMillions events without unnecessary or excessive messaging.

    All three types are available to free and premium users alike — notifications are not a premium benefit. Nothing is sent without device permission.

    Exactly three types

    There are three. Not four.

    Type When
    draw_reminder Monday 19:00 local user time → Tuesday draw
    Thursday 19:00 local user time → Friday draw
    results_available after the official winning numbers are received and validated
    jackpot_won after the official prize breakdown is validated, only if 5+2 winners ≥ 1

    1. Draw Reminder

    • Maximum one per draw. There is no additional reminder on Tuesday or Friday morning.
    • Fires at 19:00 in the user's own local timezone, not at a fixed CET hour. Because "19:00 local" happens at dozens of different instants worldwide, the job runs hourly and dispatches to whichever timezone bands are currently at the reminder hour.

    LuckyPick EuroMillions draw tomorrow Create your LuckyPick combinations.

    Tap → Combination Generation / Lucky Modes.

    The €100M+ high-jackpot variant

    It replaces the standard reminder — it is not a fourth type

    When the officially announced jackpot for the upcoming draw is €100,000,000 or more, the high-jackpot copy replaces the standard copy. This does not create an additional notification. Never send both.

    Announced jackpot Sent
    ≥ €100M High Jackpot Draw Reminder, naming the amount
    < €100M Standard Draw Reminder
    unavailable or unverified Standard Draw Reminder

    LuckyPick €145 million EuroMillions jackpot tomorrow Create your LuckyPick combinations.

    There is no separate settings switch for it. Turning Draw Reminders off silences both versions.

    2. Results Available

    Sent once the official winning numbers have been received and successfully validated.

    LuckyPick The latest EuroMillions results are available. View the latest draw results.

    Tap → the Results page for that specific draw.

    ABSOLUTE — neutral messaging

    LuckyPick does not assume a generated or saved combination was ever actually submitted for participation. It does not sell tickets and takes no part in any draw.

    This payload must never say or imply the user won. Forbidden wording:

    ❌ "Check if you won" ❌ "Check your saved picks to see if you won" ❌ "You may have won" ❌ "Your numbers won" ❌ "See if your combination won"

    State a fact about the draw, never about the user.

    3. Jackpot Won

    Separate from the €100M+ reminder: the high-jackpot reminder happens before the draw, Jackpot Won happens after it.

    No fixed sending time — LuckyPick waits for the official prize breakdown, validates it, then checks the 5 + 2 tier's number of winners.

    Prize breakdown received → validate → check 5+2 winners
   winners ≥ 1  → send Jackpot Won immediately after validation
   winners = 0  → send nothing jackpot-related

    LuckyPick EuroMillions jackpot won View the draw results.

    Tap → the Results page for the exact draw in which the jackpot was won.

    ABSOLUTE — when nobody wins, say nothing

    If the 5+2 tier has zero winners, no jackpot notification is sent, and no alternative jackpot message either. Not "jackpot not won", not "nobody won the jackpot", not "jackpot rolls over", not "bigger jackpot next draw", nor any equivalent wording.

    The normal Results Available notification may still be sent.

    This notification is about the published breakdown showing a winner somewhere — never about this user. Every localisation renders it impersonally (Jackpot geknackt, Bote acertado, Jackpot atribuído).

    Settings

    Under Settings → Notifications, three independent switches:

    • Draw Reminders — ON / OFF
    • Results Available — ON / OFF
    • Jackpot Won — ON / OFF

    Available to free and premium users. There is no €100M+ switch.

    Permission

    Device permission is required before anything is sent. Before the standard iOS/Android prompt, LuckyPick may show its own short explanation — the OS dialog can only be shown once, so it should not be spent on a user with no context.

    Declining is a normal outcome: the switches keep their values, the backend is still told about them, and nothing is ever sent. The user is not re-prompted on every launch.
